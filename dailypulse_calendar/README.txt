DAILYPULSE — календар приводів дня, версія 0.1 (редагований чорновик)

holidays_fixed.txt — 366 дат від 01.01 до 31.12, кілька подій в один день.
Формат: DD.MM|TYPE|Назва
  U — Україна: державна дата, професійний день або національна традиція
  I — міжнародна / всесвітня дата (різний ступінь офіційності)
  F — неофіційне свято, популярна традиція
  M — день пам'яті: НЕ ПРИВІТАННЯ! За замовчуванням не включається у вихідний файл
  A — авторська весела тема для порожнього дня. НЕ офіційне міжнародне свято!

holidays_movable.txt — правила для рухомих дат.
Формат: MM|WEEKDAY|NTH|TYPE|Назва
  WEEKDAY: понеділок 0 ... неділя 6; NTH: 1, 2, 3, 4 або -1 (остання)

Збірка календаря на 2027 рік:
  python generate_calendar.py --year 2027

Отримаємо calendar_2027.txt з датами YYYY-MM-DD|TYPE|Назва.
Рядків на одну дату може бути декілька.
Для 2026 року готовий calendar_2026.txt; для 2028 — 29 лютого присутнє.
Дні пам'яті включаються тільки із параметром --include-memory,
і в такому разі мають виводитися окремим нейтральним повідомленням без 🎉.

Важливо: A — вигаданий нами веселий привід, а не фальшиве «міжнародне свято».
Це редакційний чернетковий календар: офіційні та міжнародні дати варто
перевіряти перед публікацією та при оновленні законодавства.
Релігійні дати навмисно не включені. Різдво відсутнє відповідно до побажання.
